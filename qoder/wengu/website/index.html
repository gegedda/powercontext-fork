把读过的论文和笔记变成带出处、能复习的知识。 知识库由 seekdb 做混合检索，学习记忆由 PowerContext 保存——你答错的每一个知识点， 都会影响下一次出题和检索排序。

痛点

两件每天都在重复、却一直没被工具解决的事

「那句话在哪篇论文里？」

几十篇 PDF 笔记，关键词各不相同；用通用搜索只能拿到链接，拿不到「第几节第几页」的原文， 更不知道这段话和其它笔记的关系。

「我上学期学过这个，但想不起来了」

笔记工具只负责存，不负责让你记住；通用问答工具不知道你在哪薄弱， 每次都从头问起。

做法

三条链路，各用一项技术解决一件事

1

入库

PDF/Markdown 按小节切分，每段算 512 维向量，连同文档、小节、页码、年份、标签一起写进 seekdb：HNSW（cosine）建向量索引，IK 分词建全文索引。

2

检索

一个问题同时做向量召回与全文召回，用 RRF 融合，再按你的薄弱点加权， 返回带出处的原文摘录，并标注「语义第 N 名 / 关键词第 N 名」。

3

记住

每次复习的自评结果写进 PowerContext 的 artifact， 每次更新推进一个 revision；下次打开按掌握度和到期时间重新排期。

界面

五个页面，一个闭环

技术分工

两项指定技术各管一段，互不替代

技术在项目里做什么怎么核对
seekdb（嵌入式） 知识库主存储：wengu_chunks 存正文 + 512 维向量 + 元数据，wengu_docs 存文献元数据； HNSW（cosine）向量检索、IK 中文全文检索、where 下推年份/类型/文档过滤； 每次检索还会调用 seekdb 原生 hybrid_search（数据库侧 RRF）做交叉验证。 records/tech.json 的 store；records/ask.json 的 trace.vector_hits / fulltext_hits
PowerContext 1.4.1 长期记忆：学习偏好、每个知识点的掌握度与到期时间、提问历史。新建走 create_artifact， 更新走 replace_artifact（带 expected_etag），每次复习推进一个 revision； 启动时 list_atomic_memories 恢复全部状态。 records/tech.json 的 powercontext.create_artifact / replace_artifact； memory_after_restart.json
本地向量模型 bge-small-zh-v1.5 的 ONNX 版本，在本地做中文语义向量；没有模型文件时自动降级为字符 n-gram 哈希向量， 功能不中断。 records/tech.json 的 embedder
「越用越懂你」是可验证的：答错的知识点会进入薄弱列表，下一次提问若与它相关， 命中片段会被加权（界面标出「薄弱点加权」）；重启 PowerContext 后这些状态依然存在。 见 records/ask_after_restart.json 的 weak_boosted 字段。
验证

评审怎么核对（全部在一台 Linux 上跑通）

一条命令复现

cd qoder/wengu
pip install -e ".[seekdb]"
./scripts/verify.sh

依次执行：自检 → 导入示例语料 → 带出处提问 → 组卷 → 16 个单测 → 端到端验证（含重启 Server 与记忆复用），产物写入 records/。

关键结果

  • 存储：seekdbHNSW(cosine)IK 分词，34 片段 / 512 维
  • 记忆：8 条 artifactrevision 递增，重启后 state_reused = true
  • 检索：单次 7–19 ms，首选命中正确小节，薄弱点加权 1.18×
  • 测试：16 passed

需要无 Linux 也能复现时，仓库里带有 GitHub Actions 工作流（.github/workflows/wengu-verify.yml）， 会在 ubuntu-latest 上安装嵌入式 seekdb 并产出同样的 records/。

快速开始

本地跑起来

Linux（完整体验，seekdb 生效）

cd qoder/wengu
python -m venv .venv && . .venv/bin/activate
pip install -e ".[seekdb]"
wengu serve --host 0.0.0.0 --port 8000

打开 http://<机器>:8000，点「导入示例文献」即可体验。

Windows / macOS（无需 seekdb）

cd qoder/wengu
python -m venv .venv
.\.venv\Scripts\activate
pip install -e .
wengu serve

知识库自动回退 SQLite（numpy 余弦 + BM25），记忆仍由 PowerContext 提供，功能完整。

如实说明

边界与限制

  • 嵌入式 seekdb 只提供 Linux x86_64 / macOS arm64 的 wheel；Windows 上走 SQLite 回退，功能完整但「seekdb 参与」需在 Linux 验证。
  • 回答是摘录式（原文句子 + 出处），不是大模型生成的自由文本——避免无出处幻觉，也保证零 API Key 可运行。
  • 复习调度是简化版 SM-2；自动出题质量不如人工考点，示例语料因此附带了人工考点。
  • 单用户、单 scope 设计；多用户需要按 scope 扩展路由。
